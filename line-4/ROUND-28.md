refuses HTTP redirects. Its crosscheck companion inherits that transport. The
standard-library implementation keeps the original CLI, schemas, limits,
allowlisted methods, endpoint validation and dedicated User-Agent.

Try it from the repository root, without internet access:

```sh
python3 -B line-4/tools/erc20-transfer-window/test_transfer_window.py
```

All 41 native tests passed: 21 reader, 15 crosscheck and five receipt. The reader
tests include a real local HTTP server, five redirect statuses and a failing
proxy-discovery trap. Both public providers agreed on real ZTO observations
for blocks 26179316–26179317: zero reported transfers, 18 decimals, identical
boundaries and semantic receipts. Exact evidence and check results are retained.
Agreement does not establish completeness, finality or balances.
